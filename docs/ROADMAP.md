# 维护与下一阶段

V1先让完整学习闭环可用：看课程 → 预测 → 操作模型 → 独立写实现 → 保存证据 → 导入成长系统 → 周复盘。

下一轮按真实使用反馈择一实施：

1. 增加哈希表冲突与扩容、分页与外部排序模型；每项附手算基准和错误边界。
2. 提供C/汇编观察范例，结合具体机器解释编译器生成代码。
3. 在用户实际项目上选一个性能瓶颈，固定现有行为并做受控优化。
4. 仅当备份操作成为实际阻碍时再设计独立私有同步；先确定身份、冲突和恢复机制。
5. AI API服务或自动代码执行需要单独设计权限与预算，当前采用导出复盘和本机实验。

避免只扩充主题数量。至少保存一份独立解释、一份通过测试的实现和一份受控实验报告后，再扩展新的可视化。
